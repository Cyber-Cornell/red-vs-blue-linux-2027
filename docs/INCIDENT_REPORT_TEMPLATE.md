# CCDC Incident Response Report

> Keep this report in an approved private evidence location. Do not include live
> passwords, tokens, private keys, full environment values, or unredacted
> personal data. State the reporting cutoff and distinguish confirmed facts,
> analyst assessments, and unknowns.

| Field | Value |

| Prepared by and approved by | |

| Audience and handling | Team / leadership / external; TLP or event rule |
| Current phase | Detect / respond / recover / post-incident |

## Executive summary

- **Confirmed facts:** What happened, affected services, and current state.
- **Impact:** Scored-service, mission, confidentiality, integrity, and availability effects.
- **Actions taken:** The most important validated containment or recovery actions.
- **Assessment:** Likely cause or scope, with confidence and supporting evidence IDs.
- **Unknowns and decisions needed:** Open questions, risk, owner, and due time.
